# 🎨 Thumbnail Designer Portfolio

A modern, responsive portfolio website showcasing creative YouTube thumbnail designs, services, and design work.

Built to present my thumbnail designing work through a clean interface, smooth animations, and an engaging visual experience.

## ✨ Features

* Modern dark-themed UI with premium visual styling.
* Responsive design for desktop, tablet, and mobile.
* Featured thumbnail carousel.
* Portfolio gallery with category filters.
* Image preview with lightbox functionality.
* Services and design process sections.
* About section.
* Frequently Asked Questions (FAQ).
* Email-based contact section.
* Smooth animations and interactive elements.

## 🚀 Run Locally

### 1. Clone the repository

```bash
git clone https://github.com/namanagarwal17/thumbnail-designer-portfolio.git
```

### 2. Open the project directory

```bash
cd thumbnail-designer-portfolio
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

Open the local URL displayed in your terminal.

## 📦 Build for Production

```bash
npm run build
```

To preview the production build:

```bash
npm run preview
```
